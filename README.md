
# Prática 01 — Minhas Tarefas

## Sobre o projeto

Aplicativo de gerenciamento de tarefas desenvolvido utilizando React Native e Expo Snack.

## Funcionalidades

- Adicionar tarefas.
- Marcar tarefas como concluídas.
- Remover tarefas.
- Exibir mensagem quando a lista estiver vazia.
- Interface simples e acessível.

## Tecnologias utilizadas

- React Native
- JavaScript
- Expo Snack
